PoE Korean Helper 개인정보처리방침

시행일: 2026년 9월 17일

대상: Chrome 확장 프로그램 “울보천사의 PoE 도우미 (PoE Korean Helper)”

요약: PoE Korean Helper 개발자는 사용자의 개인정보를 자체 서버에 수집하거나 판매하지 않습니다. 확장 프로그램은 기능 제공을 위해 지원되는 웹사이트의 페이지 내용, 공개 거래 아이템 정보, 사용자가 기능 실행을 위해 제공한 클립보드의 게임 아이템 정보, 확장 프로그램 설정값 등을 브라우저 내에서 처리할 수 있습니다. 일부 기능은 공개 게임 데이터·거래 정보·시세 정보를 조회하기 위해 제3자 서비스에 네트워크 요청을 보냅니다.

1. 개요

본 개인정보처리방침은 “울보천사의 PoE 도우미 (PoE Korean Helper)” Chrome 확장 프로그램(이하 “확장 프로그램”)이 어떤 데이터를 처리하고 어떤 목적으로 사용하는지 설명합니다.

확장 프로그램 개발자는 사용자 개인정보를 수집하기 위한 별도의 백엔드 서버를 운영하지 않으며 사용자 데이터를 판매하지 않습니다.

2. 확장 프로그램이 처리할 수 있는 정보

2.1 확장 프로그램 설정 및 로컬 데이터

확장 프로그램은 언어, 거래소 선택, 번역 옵션, 북마크, 주시 목록, UI 설정 등 기능 제공에 필요한 설정과 데이터를 chrome.storage 등 브라우저 저장소에 저장할 수 있습니다. 이러한 데이터는 기본적으로 사용자의 브라우저 환경에서 저장 및 처리됩니다.

2.2 지원 사이트의 페이지 콘텐츠

번역, 거래 편의 기능, 아이템 정보 표시, 북마크 및 주시 기능을 제공하기 위해 사용자가 현재 보고 있는 지원 사이트의 페이지 콘텐츠를 읽고 처리할 수 있습니다. 여기에는 아이템 이름, 아이템 옵션, 가격, 거래 목록에 공개된 계정/캐릭터 정보, 검색 결과 및 URL 정보 등이 포함될 수 있습니다.

이 정보는 확장 프로그램 기능 수행을 위해 사용되며 개발자가 운영하는 별도 서버에 사용자 프로필을 만들기 위한 목적으로 전송되지 않습니다.

확장 프로그램은 지원되는 Path of Exile 관련 사이트를 판별하고, 게임 버전 확인, SPA(Single Page Application) 페이지 이동 처리, 북마크 및 거래 기능을 제공하기 위해 현재 또는 열려 있는 브라우저 탭의 URL을 처리할 수 있습니다. 이러한 탐색 정보는 해당 사용자 기능 제공 목적으로만 처리되며, 프로파일링이나 광고 목적으로 개발자가 운영하는 서버에 전송되지 않습니다.

2.3 클립보드 데이터

클립보드 관련 기능이 사용 설정되어 있고 사용자가 해당 기능을 실행하는 경우, 확장 프로그램은 Path of Exile에서 복사한 아이템 정보 등 클립보드 텍스트를 읽어 검색, 필터 생성, 번역 또는 아이템 정보 처리에 사용할 수 있습니다.

클립보드 내용은 해당 기능 수행 목적으로 처리되며 개발자가 운영하는 서버에 저장되지 않습니다.

2.4 거래 및 게임 데이터

거래소 기능을 제공하기 위해 아이템 식별자, 검색 식별자, 거래 검색 조건, 리그, 가격 또는 공개 거래 목록 정보 등을 처리할 수 있습니다. 이러한 정보는 Path of Exile 관련 서비스에 요청을 보내거나 화면에 결과를 표시하기 위해 사용됩니다.

3. 데이터 사용 목적

  • Path of Exile 관련 웹사이트의 한국어 번역 및 용어 변환
  • 카카오/GGG 거래소 간 이동 및 거래 검색 편의 기능
  • 아이템 정보의 한국어/영어 변환 및 복사
  • 아이템 북마크, 주시 목록, 비교 및 상태 표시
  • 게임 아이템 정보 기반 검색 및 필터 생성
  • 공개 게임 데이터, 시세 및 아이템 정보 조회
  • 사용자 환경설정 저장 및 UI 맞춤 설정

4. 제3자 서비스 및 외부 요청

확장 프로그램의 일부 기능은 공개 게임 데이터, 거래 정보, 시세 또는 번역에 필요한 자료를 조회하기 위해 제3자 서비스와 통신할 수 있습니다. 기능에 따라 다음 서비스가 포함될 수 있습니다.

  • Path of Exile / Grinding Gear Games 공식 웹사이트 및 거래 API
  • Kakao Games Path of Exile 한국 서비스 및 거래소 (poe.kakaogames.com)
  • poe.ninja
  • PoE2Scout
  • PoEDB / PoE2DB
  • GitHub 또는 기타 공개 데이터 저장소(번역/게임 데이터 업데이트에 사용되는 경우)

이러한 네트워크 요청이 발생할 경우 사용자의 브라우저는 일반적인 웹 요청과 마찬가지로 IP 주소, User-Agent 등 통신에 필요한 기술적 정보를 해당 서비스에 제공할 수 있습니다. 이러한 정보의 처리는 각 제3자 서비스의 개인정보처리방침 및 이용약관의 적용을 받습니다.

확장 프로그램은 광고 목적의 사용자 프로파일링이나 사용자 데이터 판매를 위해 제3자 서비스에 개인정보를 전송하지 않습니다.

5. 호스트 권한 사용

확장 프로그램은 지원되는 Path of Exile 관련 웹사이트에서 번역 및 거래 편의 기능을 제공하기 위해 해당 사이트에 대한 호스트 권한을 사용할 수 있습니다.

  • https://poe.kakaogames.com/*
  • https://www.pathofexile.com/* 및 지원되는 Path of Exile 공식 도메인
  • Maxroll 및 Mobalytics의 Path of Exile 관련 페이지
  • 기능 제공에 필요한 공개 데이터/API 사이트

6. 데이터 보관 및 삭제

설정, 북마크, 주시 목록 등 브라우저에 저장되는 데이터는 사용자가 확장 프로그램 기능을 이용하는 동안 로컬에 유지될 수 있습니다. 사용자는 확장 프로그램의 관련 삭제 기능을 사용하거나 Chrome에서 확장 프로그램을 제거하여 해당 로컬 데이터를 삭제할 수 있습니다.

개발자는 자체 서버에 사용자별 개인정보 데이터베이스를 운영하지 않으므로 개발자 서버에 보관된 사용자 개인정보에 대한 별도의 삭제 절차는 없습니다.

7. 데이터 판매 및 광고

확장 프로그램 개발자는 사용자의 개인정보를 판매하지 않습니다. 또한 사용자 데이터를 관심 기반 광고 또는 행동 광고 프로파일을 구축하는 목적으로 사용하지 않습니다.

8. 보안

확장 프로그램은 기능 수행에 필요한 범위 내에서만 데이터에 접근하도록 설계합니다. 다만 인터넷을 통한 제3자 서비스와의 통신에는 해당 서비스와 네트워크 환경의 보안 정책이 적용됩니다.

9. 아동의 개인정보

확장 프로그램은 아동의 개인정보를 의도적으로 수집하도록 설계되지 않았으며 개발자는 아동의 개인정보를 별도로 수집하거나 보관하지 않습니다.

10. 개인정보처리방침 변경

확장 프로그램 기능이나 데이터 처리 방식이 변경되는 경우 본 개인정보처리방침을 업데이트할 수 있습니다. 중요한 변경이 있는 경우 이 페이지의 시행일을 갱신합니다.

Privacy Policy for PoE Korean Helper

Effective Date: September 17, 2026

Applies to: “PoE Korean Helper” Chrome Extension

Summary: The developer of PoE Korean Helper does not collect personal information on a developer-operated backend and does not sell user data. The Extension may process supported webpage content, public trade-item data, clipboard text that the user provides for Extension features, and Extension settings locally in the browser. Some features make network requests to third-party services to retrieve public game, trade, translation, or pricing data.

1. Introduction

This Privacy Policy explains how the “PoE Korean Helper” Chrome Extension (“the Extension”) processes information and how that information is used.

The developer does not operate a separate backend service for collecting user personal information and does not sell user data.

2. Information the Extension May Process

2.1 Extension Settings and Local Data

The Extension may store settings and feature data such as language preferences, trade-site preferences, translation options, bookmarks, watch lists, and UI preferences using browser storage such as chrome.storage. This information is generally stored and processed in the user's browser environment.

2.2 Content on Supported Websites

To provide translation, trade utilities, item display, bookmarking, and watch-list features, the Extension may read and process content on supported pages currently visited by the user. This may include item names, item modifiers, prices, publicly displayed account or character information in trade listings, search results, and URL information.

This information is used to provide Extension functionality and is not sent to a developer-operated server for the purpose of building user profiles.

The Extension may process the URLs of the current or open browser tabs to identify supported Path of Exile-related sites, determine the game version, handle Single Page Application (SPA) navigation, and provide bookmark and trade features. This browsing information is processed only to provide these user-facing features and is not sent to a developer-operated server for profiling or advertising.

2.3 Clipboard Data

When a clipboard-related feature is enabled and invoked by the user, the Extension may read clipboard text, such as item information copied from Path of Exile, for search, filter generation, translation, or item-processing features.

Clipboard content is processed for the requested feature and is not stored on a server operated by the developer.

2.4 Trade and Game Data

The Extension may process item identifiers, search identifiers, trade search parameters, league information, prices, or public trade-listing information to provide trade-related features. Such data may be used to send requests to Path of Exile-related services or to display results to the user.

3. Purposes of Processing

  • Korean translation and terminology conversion on Path of Exile-related websites
  • Trade-site navigation and convenience features between Kakao and GGG services
  • Korean/English conversion and copying of item information
  • Item bookmarks, watch lists, comparison, and status display
  • Search and filter generation based on game item information
  • Retrieval of public game, pricing, and item information
  • Saving user preferences and customizing the Extension UI

4. Third-Party Services and Network Requests

  • Official Path of Exile / Grinding Gear Games websites and trade APIs
  • Kakao Games Path of Exile services and trade site (poe.kakaogames.com)
  • poe.ninja
  • PoE2Scout
  • PoEDB / PoE2DB
  • GitHub or other public data repositories when used for translation/game-data updates

When such network requests are made, the user's browser may provide technical information required for normal web communication, such as IP address and User-Agent, to the relevant third-party service. Such processing is governed by the privacy policies and terms of those services.

The Extension does not transmit personal information to third parties for advertising, behavioral profiling, or sale of user data.

5. Host Permissions

  • https://poe.kakaogames.com/*
  • https://www.pathofexile.com/* and supported official Path of Exile domains
  • Path of Exile-related pages on Maxroll and Mobalytics
  • Public data/API sites required for enabled features

6. Data Retention and Deletion

Settings, bookmarks, watch lists, and similar locally stored information may remain in the browser while the Extension is in use. Users may remove such data through relevant Extension controls or by uninstalling/removing the Extension from Chrome.

Because the developer does not maintain a developer-operated database of user personal information, there is no separate developer-server account deletion process for such personal data.

7. Sale of Data and Advertising

The developer does not sell users' personal information. User data is not used to build interest-based or behavioral advertising profiles.

8. Security

The Extension is designed to access information only as needed to provide its features. Communications with third-party internet services are additionally subject to the security practices of those services and the user's network environment.

9. Children's Privacy

The Extension is not designed to intentionally collect personal information from children, and the developer does not knowingly maintain personal information about children.

10. Changes to This Privacy Policy

This Privacy Policy may be updated when Extension features or data-handling practices change. If material changes are made, the Effective Date shown on this page will be updated.
